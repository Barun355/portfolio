Principles

Know how it’s built before you break it

Shipping auth flows, APIs, and deploys is how I learned where they get misconfigured.

Every trust boundary is an attack surface

A device token, a webhook URL, and a database port are all doors. Know which ones are open.

Defaults are the real entry points

My own database was breached through a default password, not a clever exploit.

Label what’s real

Shipped, practiced in labs, or learning. Never blurred together.
