# Work Page

URL: https://ramx.in/work

## Purpose

Expanded professional history. It turns the three-row home preview into a complete chronological record.

## Section order

1. Global header
2. H1 “Work Experience”
3. Introductory sentence
4. Six experience records
5. Quote card
6. Global footer

## Experience record anatomy

- Company name
- Optional current-status badge
- Role
- Date range
- Location and work mode
- “Technologies & Tools” subheading
- Technology badges/icons
- “What I’ve done” subheading
- Outcome/responsibility bullet list

## Records observed

4. Prepeasy — Founding Engineer

## Hierarchy

- Page title is H1.
- Companies are H3.
- Internal record labels use H4.
- There is no H2 between the page title and company H3 headings.

The visual hierarchy works, but the skipped semantic level is avoidable.

## Content pattern

The strongest bullets combine:

- Ownership: architected, built, deployed
- Product context
- Measured result
- Technical implementation

Example pattern: an AI interview platform paired with cost reduction from `$7` to `$0.30` per session.

## Responsive behavior

- Full details remain visible on mobile.
- Date and location switch to shorter labels.
- Technology items wrap.
- Long responsibility bullets remain a single vertical reading flow.

## Components

- Page title block
- Full experience card/record
- Current-status badge
- Metadata row
- Technology badge list
- Responsibility list

## Reusable ideas

- Home preview and dedicated detail page share the same data model.
- Measurable outcomes appear inside the relevant role.
- Technologies support each role instead of living only in a global skill wall.
- Current role is visibly marked.

## Weaknesses to improve

- Six fully expanded records make the page long.
- Technology lists repeat heavily.
- Several bullets describe duties rather than outcomes.
- Heading levels skip H2.
- No direct links from achievements to related case studies.
