Consultifi Data

Feb 2026 – Jun 2026

Full Stack Engineer

Problem

Manufacturing operations needed software that matched real floor and office workflows: inventory, production, dispatch, and devices that keep working when the network drops.

What I built and owned

  • Production ERP workflows across frontend, backend services, databases, and device integrations.
  • React / Electron apps, SQLite / PostgreSQL, REST APIs, QR-based workflows, and real-time updates.
  • Connected stations: USB scales, thermal printers, QR identities, and Raspberry Pi services, with offline-first sync, retries, and idempotent writes.

Attack surface

Physical devices on a factory floor, the tokens they carry, the sync queue that replays events, and the boundary between plants.

Controls

  • A token per station instead of one shared key, mapped server-side to a single plant.
  • 401 for unknown callers and 403 for the wrong plant.
  • An event id in the data model, so a replayed event can’t double-count stock.

Result

Operations keep moving when the network drops, and one compromised box doesn’t speak for the whole factory. Client identities stay confidential.
